# QuestHub — Квест-комнаты и антикафе (Вариант 14)

Веб-приложение на **Python 3.11+ / Django 4.2 LTS** для бронирования квест-комнат по расписанию с автоматическим расчётом стоимости, учётом доплаты за участников сверх 4 человек и контролем 30-минутного технического перерыва.

## Реализованная функциональность

1. **Серверная часть на Django + ORM (SQLite)**: 12 нормализованных сущностей (`UserProfile`, `Genre`, `AgeRating`, `QuestRoom`, `TariffSlot`, `SessionSchedule`, `Team`, `ExtraOption`, `Booking`, `BookingExtraOption`, `GameResult`, `Review`), связи `1:N` и явная `M:N` (`through='BookingExtraOption'`), ограничения БД (`CheckConstraint`, `UniqueConstraint`).
2. **Особое требование Варианта 14 (`booking/services.py`)**:
   - Бронирование выполняется строго по доступной сетке сеансов с проверкой заблокированных слотов (`SessionSchedule.is_blocked`).
   - Базовая цена рассчитана на команду 2–4 человека с учётом тарифного слота (`Утренний`, `Дневной`, `Вечерний`, `Ночной`).
   - За каждого участника сверх 4 (до `max_players` комнаты) автоматически начисляется доплата.
   - Между соседними бронированиями одного квеста удерживается обязательный **технический перерыв 30 минут** (внутри `transaction.atomic()` с `select_for_update()`), а при переносе бронирования обновляется связанный `SessionSchedule`.
3. **Аутентификация и разграничение ролей**:
   - Регистрация, вход (с ограничением попыток), выход (POST), смена пароля, защита от IDOR (`403 Forbidden`).
   - **Игрок (капитан)**: управление своими командами, бронированиями, отзывами, печатный талон и экспорт своих броней в CSV.
   - **Актёр-аниматор**: просмотр назначенных ему смен/бронирований с услугой актёра (`/actor/schedule/`).
   - **Оператор / Администратор**: управление квестами, фиксация результатов в таблице рекордов, сводная финансовая аналитика (`/analytics/`), встроенная админка (`/admin/`).
4. **Полный CRUD на сайте**: команды (`Team`), бронирования (`Booking`), отзывы (`Review`), квесты (`QuestRoom` для оператора/администратора).
5. **Каталог, аналитика и `fetch`**: поиск, 4 фильтра, сортировка по 4 полям, пагинация по 20 записей с сохранением параметров, JSON API предрасчёта цены и слотов, диаграмма `<canvas>` в аналитике.
6. **Отладка, безопасность и ошибки**: `django-debug-toolbar` (подключается при `DEBUG=True`), проверка изображений через Pillow, отсутствие `|safe` и inline-стилей, `DEBUG=False` по умолчанию, `.env.example`, `.gitignore`, страницы `403.html`, `404.html`, `500.html`, ротируемый лог `logs/app.log`, команда `seed_data` (32 квеста) и 12 автотестов.

## Быстрый запуск

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate

pip install -r requirements.txt
cp .env.example .env

python manage.py migrate
python manage.py seed_data
python manage.py test

# Для режима разработки с Django Debug Toolbar задайте DEBUG=True в .env:
python manage.py runserver
# Для проверки кастомных страниц 403/404 при DEBUG=False локально:
python manage.py runserver --insecure
```
