# QuestHub — Квест-комнаты и антикафе (Вариант 14)

Веб-приложение на **Python 3.11+ / Django 4.2 LTS** для бронирования квест-комнат по расписанию с автоматическим расчётом стоимости, учётом доплаты за участников сверх 4 человек и контролем 30-минутного технического перерыва.

## Выполненные требования

1. **Серверная часть на Django + ORM (SQLite)**: 12 нормализованных сущностей (`UserProfile`, `Genre`, `AgeRating`, `QuestRoom`, `TariffSlot`, `SessionSchedule`, `Team`, `ExtraOption`, `Booking`, `BookingExtraOption`, `GameResult`, `Review`), связи `1:N` и явная `M:N` (`through='BookingExtraOption'`), ограничения БД (`CheckConstraint`, `UniqueConstraint`).
2. **Особое требование Варианта 14 (`booking/services.py`)**:
   - Базовая цена рассчитана на команду 2–4 человека с учётом тарифного слота (`Утренний`, `Дневной`, `Вечерний`, `Ночной`).
   - За каждого участника сверх 4 (до `max_players` комнаты) автоматически начисляется доплата.
   - Между соседними бронированиями одного квеста удерживается обязательный **технический перерыв 30 минут** (проверка выполняется в `transaction.atomic()` с `select_for_update()`).
3. **Аутентификация и разграничение прав**: регистрация, вход (с защитой от перебора паролей), выход (POST), смена пароля, защита от IDOR (`403 Forbidden` при попытке открыть чужую бронь или команду).
4. **Полный CRUD на сайте**: команды (`Team`), бронирования (`Booking`), квесты (`QuestRoom` для администратора/оператора), отзывы (`Review`).
5. **Каталог**: поиск, 4 фильтра, сортировка по 4 полям, пагинация по 20 записей с сохранением параметров.
6. **Аналитика и `fetch` JSON API**: страница сводных показателей с агрегатными запросами и диаграммой `<canvas>`, живой предрасчёт цены и слотов через `fetch`.
7. **Экспорт, печать, загрузка изображений, почта, ошибки**: CSV-экспорт (`utf-8-sig`), печатный талон, проверка типа/размера/сигнатуры изображений через Pillow, консольный email-бэкенд, собственные страницы `403.html`, `404.html`, `500.html`, ротируемый лог `logs/app.log`.

## Быстрый запуск

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate

pip install -r requirements.txt
cp .env.example .env

python manage.py migrate
python manage.py seed_data
python manage.py test

# Запуск с DEBUG=False (для проверки страниц 403/404 и статики локально):
python manage.py runserver --insecure
```
